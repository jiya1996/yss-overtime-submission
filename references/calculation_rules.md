# 加班时长计算规则（赢时胜）

本文档是**计算逻辑的唯一权威来源**。脚本里的所有计算行为都必须能在这里找到对应规则。

---

## 总览

加班时长按**当天日期类型**分两套规则计算：

| 日期类型 | 触发条件 | 默认使用方式 | 可选使用方式 |
|---------|---------|------------|------------|
| 工作日 | 周一~周五，非法定假日 | 奋斗积分 | 仅奋斗积分 |
| 非工作日 | 周六、周日，或法定假日 | 调休 | 调休 / 奋斗积分 |

> **注意**：日期类型不需要脚本判断——SHR 系统在选择"奋斗日期"时会自动带出"奋斗类型"字段。脚本只需读取 SHR 返回的字段即可。

---

## 规则 1：工作日加班

### 1.1 公式

```
实际加班时长 = 下班打卡时间 − 19:00
```

> 19:00 是公司规定的加班起点（之前算正常工作时间 + 1h 晚餐）。

### 1.2 提交资格

实际加班时长必须 **> 1 小时** 才能提交。等于 1h 也不行。

### 1.3 取整规则（向下取整到 0.5h）

| 实际时长（h:m） | 可提交时长 |
|----------------|-----------|
| < 1h00         | ❌ 不能提（不满 1 小时）|
| = 1h00         | ❌ 不能提（必须**严格** > 1h）|
| 1h01 ~ 1h29    | 1.0h |
| 1h30 ~ 1h59    | 1.5h |
| 2h00 ~ 2h29    | 2.0h |
| 2h30 ~ 2h59    | 2.5h |
| 3h00 ~ 3h29    | 3.0h |
| 3h30 ~ 3h59    | 3.5h |
| ...            | 类推（每 30min 一档）|

> ⚠️ **临界值 1h00 不能提**——文档规定"超过 1 小时"，exact 1h00 不算超过。
> 算法实现：`floor(实际小时数 × 2) / 2`，前提是实际时长 > 1h。

### 1.4 工作日规则示例（来自实际打卡）

| 日期 | 打卡 | 实际计算 | 报 |
|------|------|---------|-----|
| 2026-04-20 周一 | 08:46, **21:33** | 21:33 - 19:00 = 2h33min | **2.5h** |
| 2026-04-21 周二 | 08:44, 18:46 | 18:46 - 19:00 = 负数 | **不报** |
| 2026-04-22 周三 | 08:49, **21:10** | 21:10 - 19:00 = 2h10min | **2.0h** |
| 2026-04-23 周四 | 08:45, **22:07** | 22:07 - 19:00 = 3h7min | **3.0h** |

## 规则 2：非工作日加班

### 2.1 公式

```
实际加班时长 = 下班打卡 − 上班打卡 − 午餐扣除 − 晚餐扣除
```

### 2.2 午餐扣除（12:00–13:00）

| 上班打卡时间 | 是否扣午餐 | 解释 |
|------------|----------|------|
| < 12:00     | ✅ 扣 1h  | 工作时段完整覆盖了 12-13，扣午餐 |
| 12:00 ~ 13:00 | ❌ 不扣 | 上班时正在午餐时段，那部分时间算工时 |
| > 13:00     | ❌ 不扣 | 工作时段在午餐之后才开始 |

### 2.3 晚餐扣除（18:00–19:00）

**完整规则**：必须 **同时** 满足以下两个条件，才扣 1h 晚餐：
- 上班打卡 **< 18:00**（即开始工作时还在晚餐之前）
- 下班打卡 **≥ 19:00**（即工作时段持续到晚餐之后）

| 上班打卡 | 下班打卡 | 是否扣晚餐 | 解释 |
|---------|---------|----------|------|
| < 18:00  | ≥ 19:00  | ✅ 扣 1h  | 完整跨越 18-19，假定吃了晚餐 |
| < 18:00  | < 19:00  | ❌ 不扣 | 没工作到 19 点之后，跨入晚餐的部分算加班 |
| ≥ 18:00  | ≥ 19:00  | ❌ 不扣 | **上班时晚餐时段已开始/已过，员工没机会吃晚餐** |
| ≥ 18:00  | < 19:00  | ❌ 不扣 | 工作时段完全在晚餐之内（极端罕见）|

> **直觉理解**：
> - 18:30 下班 → 没工作到 19 点，跨入晚餐那 30min 算加班
> - 18:30 上班 → 错过完整晚餐，工作时段全部算加班
> - 11:48 上班、20:50 下班 → 完整跨越晚餐时段，扣 1h

### 2.4 取整规则

跟工作日相同：向下取整到 0.5h，最低 1h，必须 >1h 才可提交。

### 2.5 非工作日规则示例（来自实际打卡）

| 日期 | 打卡 | 总时长 | 午餐 | 晚餐 | 净加班 | 报 |
|------|------|-------|------|------|--------|-----|
| 2026-04-18 周六 | **11:48**, **20:50** | 9h2min | 扣 1h（11:48<12:00）| 扣 1h（20:50≥19:00）| 7h2min | **7.0h** |
| 2026-04-19 周日 | **12:02**, 18:19 | 6h17min | 不扣（12:02 在 12-13 区间）| 不扣（18:19<19:00）| 6h17min | **6.0h** |
| 假设 周六 | **13:30**, 18:30 | 5h0min | 不扣（13:30>13:00）| 不扣（18:30<19:00）| 5h0min | **5.0h** |

### 2.6 边界情况手册

| 情形 | 处理 |
|------|------|
| 上班打卡 ≥ 19:00（深夜补班）| 总时长直接 = 下班 − 上班，无任何扣除 |
| 上班打卡在午餐 13:00 整 | 算"在 12-13 区间"，不扣午餐 |
| 下班打卡正好 19:00 整 | 扣晚餐 1h |
| 跨天打卡（次日 1:00 下班）| 当前 skill 不支持，需用户手动处理 |
| 没下班打卡（漏打）| 当天跳过，提示用户去补卡 |

## 规则 3：使用方式（调休 vs 奋斗积分）

| 日期类型 | 默认 | 可改 | 业务理由 |
|---------|------|------|---------|
| 工作日 | 奋斗积分 | ❌ 不可改 | 公司规定 |
| 非工作日 | **调休** | ✅ 可改奋斗积分 | 调休能用来抵假，价值高于 1.5×小时工资 |

> **为什么默认调休**：调休 1h ≈ 1h 假期，按月薪 X 元算每小时价值远高于奋斗积分的 30 元/h。优先调休是最优经济选择。

## 规则 4：差集计算（去重）

**目标**：从「应提交清单」里减去「已提交清单」，得到「待提交清单」。

**去重键**：`(日期)` 单一键。**同一天不允许重复提交**。

| 应提交 | 已提交 | 待提交 |
|--------|--------|--------|
| 04-20 周一 2.5h | 04-20 周一 2.0h（已提）| ❌ 跳过 |
| 04-22 周三 2.0h | （无）| ✅ 提交 |

> ⚠️ 即使已提交时长 ≠ 应提交时长（如算出 2.5h 但只提了 2h），**当前 skill 仍然跳过这一天**。如需修正，请用户手动撤销 / 退回原单后重提。

## 规则 5：单日超过 8h 的分段提交

SHR 对同一天的单条奋斗时间有 8h 校验。非工作日加班净时长超过 8h 时，必须拆成多条提交，并且每条的**奋斗开始时间**要不同。

### 5.1 拆分策略

默认按 `8h + 剩余时长` 拆分，后续分段从上一段结束后 1 分钟开始：

| 日期 | 打卡 | 净加班 | 拆分 |
|------|------|--------|------|
| 2026-05-10 周日 | 09:44, 22:58 | 11h | 第 1 条 09:44-18:44 报 8h；第 2 条 18:45-21:45 报 3h |

> 实战验证：如果两条都沿用 SHR 自动带出的同一个开始时间（例如都从 09:44 开始），系统会报「奋斗时间不能超过8个小时」。必须把第二条的小时、分钟都设成新的开始时间。

### 5.2 扣餐规则在分段里的处理

每个分段单独计算休息时长：

| 分段开始 | 分段结束 | 休息时长 |
|----------|----------|----------|
| 09:44 | 18:44 | 午餐 60 分钟 |
| 18:45 | 21:45 | 不扣餐 = 0 分钟 |

### 5.3 提交流程要求

超过 8h 的同一天建议**分批提交**：

1. 第一批提交第一段（可和其他日期一起提交）。
2. 第二批单独提交剩余分段。
3. 第二段必须覆盖 SHR 自动带出的奋斗开始时间、结束时间、休息时长和隐藏的申请时长缓存。

这样能避开 SHR 多条创建页在同一张单内对同一天累计时长的校验。

## 单元测试用例（必跑）

`scripts/calculator.py` 必须通过以下用例：

```python
# 工作日
assert calc_workday("21:33") == 2.5
assert calc_workday("21:10") == 2.0
assert calc_workday("22:07") == 3.0
assert calc_workday("18:46") is None  # 没加班
assert calc_workday("19:30") is None  # 只 0.5h，<1h 不能提
assert calc_workday("20:00") is None  # exact 1h，必须 >1h
assert calc_workday("20:01") == 1.0   # 1h1min → 1h

# 非工作日
assert calc_holiday("11:48", "20:50") == 7.0  # 扣午晚餐
assert calc_holiday("12:02", "18:19") == 6.0  # 都不扣
assert calc_holiday("13:30", "18:30") == 5.0  # 都不扣
assert calc_holiday("09:00", "19:00") == 8.0  # 上班<12，下班=19，扣午餐+晚餐 = 10-2=8
assert calc_holiday("13:00", "18:00") == 5.0  # 边界：13:00 在 12-13 区间，不扣午餐

# 单日超过 8h 拆分
bill = OvertimeBill(date(2026, 5, 10), "周日", "09:44", "22:58", 11.0, "非工作日", "奋斗积分")
parts = split_overtime_bill(bill)
assert [(p.hours, p.submit_start, p.submit_end, p.rest_minutes) for p in parts] == [
    (8.0, "09:44", "18:44", 60),
    (3.0, "18:45", "21:45", 0),
]
```
